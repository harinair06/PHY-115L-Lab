# PHY-115L-Lab
This repository contains Python code I used throughout my PHY 115L labs.



Lab 1: Data Analysis Bootcamp (9/4/26)
 Calculate the mean and standard deviation of a set of measurements.
 Distinguish between statistical error and systematic error.
 Report measurement results in a correct manner.
 Propagate errors.
 State whether two results are the same or different within experimental error.
 Carry out a nonlinear fit of a model to data with a computer program

Lab 2: Vibrations of Strings
 Learn how to use a data acquisition system and its FFT function.
 Listen to the sound produced by a plucked string and measure its spectrum. Determine
the frequency components that are present in the spectrum. Observe how the sound and
the spectrum depend on the way that the string is plucked.
 Determine whether you can produce a vibration of the plucked string in its fundamental
mode only. Determine whether you can produce a vibration of the plucked string in its
second harmonic only.
 Measure how the fundamental mode vibration frequency of a clamped string depends on
the length of its vibrating section. Determine the functional relationship between these
quantities.
 Measure how the fundamental mode vibration frequency of a clamped string depends on
the tension in the string. Determine the functional relationship between these quantities.
